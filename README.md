
🚀 Telegram Private Channel Clone Bot

A powerful Telegram Forward/Clone Bot made with Pyrogram.

Features:

Bulk Message Clone

Private Channel Support

FloodWait Handling

Heroku Deploy Support

Auto Progress Update

Media + Text Copy



---

[![Deploy](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/creator154/Forward-bot-bulk)



---

🔥 Required Variables

Variable	Description

API_ID	Telegram API ID
API_HASH	Telegram API HASH
BOT_TOKEN	Telegram Bot Token



---

📌 Commands

/start

/clone @source @destination

Example:

/clone @movieschannel @backupchannel


---

📢 Important

Bot must be admin in destination channel.

Private channels require joined account/userbot support.

Avoid too much spam to prevent FloodWait.
